Google Apps Script example

PDF document generator

Enter the project details, choose a Google Doc or Google Sheet layout, and download the finished PDF.

Template source

Best for a narrative, letter-style PDF.

Generation flow

  1. Validate the submitted values on the server.
  2. Copy the selected Drive template.
  3. Replace matching {{TOKENS}}.
  4. Export the temporary file as PDF.
  5. Return it directly to this browser.
  6. Move the temporary source to Trash.

Google Doc: preserves document typography, headers, footers, tables and page layout.
